# Newdri Sessão

Hub de sessão para clínica e paciente.

- Registra data, hora, duração, protocolo
- Autohipnose, meditação, EMDR, espiral, cores + flash (PsicoTron), metáfora
- FC e GSR início/fim, profundidade, notas
- Clone por paciente (código local)
- Exporta CSV e JSON

Abrir: baixe `index.html` ou ative GitHub Pages (Settings → Pages → Deploy from branch `main` / root).

Dados ficam no aparelho (localStorage). Não sobem sozinhos para a nuvem.
